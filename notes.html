Notes · Room 11 · Snapshot 2026-11-22

A room built
around the file.

This is not a link directory. It is a small research library: a curatorial wall in front, complete repository snapshots behind it. The selection is deliberately narrow — four authors whose work set the vocabulary for creative WebGL and WebGPU, plus 41 Codrops pieces chosen for their mechanics rather than their novelty.

01

Why these four

Saharan’s Oimo works are compact, complete worlds. David Li’s fluid studies became the reference implementation for a generation of WebGL liquids. Amanda Ghassaei moves between origami, CFD and GPU compute without losing the material feeling. Jeantimex takes the same physics into WebGPU. Together they form a line from shader to simulation to surface.

02

Why Codrops, twice

Codrops is an archive of mechanics: a hover that reads direction, a grid that reflows, a page that folds. Forty-one pieces are split into Motion studies and Built worlds, because transitions and layouts are different reading experiences even when they share an author.

03

What “complete” means

Each card’s Source link opens a folder inside this repository. The folder is a snapshot of the upstream repository at 2026-11-22, including its scripts, assets, README and licence. Nothing is a reimplementation, a thumbnail-only entry, or a link back to the original site.

04

What “local” means

Demos are opened from files served by this repository. A few pieces need a real GPU, WebGPU or a pointer; Saharan Water, WebGPU Water, Lenticular Lens and Raindrop will not render in every browser. The source is still complete, and the failure is a capability boundary, not a missing file.

05

Rights, plainly

All works remain © their original authors. Codrops demos are published under the terms attached to each upstream repository. This room is a study archive: it does not relicence the work, imply commercial availability, or strip attribution. Licence files stay inside every source/ folder. If you want to reuse something, start there and then ask the author.

06

The missing four

Four very large Jeantimex and Amanda repositories were left out to keep this Pages site under the hosting ceiling — including geospatial, tokyo, glass-effect-webgpu and botanigram. This is a size decision, not a judgement about their quality. The selected 53 repositories total roughly 202 MB of source.

Upstream starting points: saharan/works, dli, amandaghassaei, jeantimex, codrops. The room itself is built with plain HTML, CSS and a small filter script.
